# Store Presentation — Build 01 Direction

## What is ready
Three distinct art systems, one draft icon direction per game, one labeled feature-graphic draft per game, draft titles/subtitles/Google short descriptions, actual prototype captures and a parent-facing internal presentation page at `play/storefront-review.html`.

All titles and Apple subtitle drafts are at most 30 characters; each Google short description draft is at most 80. This corrects overly long subtitle concepts from the earlier planning documents. These are unpublished drafts, not platform validation.

## Game-specific emphasis
| Game | First visual | Emotional message | Proof to show in final screenshots |
|---|---|---|---|
| Pet | One expressive leaf-eared friend on warm yellow | A world the child can make their own | Actual pet selection, decoration placement and illustrated memories |
| Garage | Bold original buggy with oversized wheels | A creation that actually changes how it plays | Actual part swaps, visible terrain performance and local track editor |
| Lab | Friendly inventor robot and clear interactive light path | Discovery through doing | Actual puzzle manipulation, successful reflection and useful hint |

## Final screenshot sequence
1. The core value, shown in genuine gameplay—not a marketing-only screen.
2. The creation/manipulation action.
3. The first satisfying result.
4. The first distinctive mechanic.
5. The second distinctive mechanic.
6. Clear parent-facing value and accurate offline/privacy/purchase statements.

Do not advertise a 50-object catalog, 12 tracks, 24 puzzles, cross-device restore, validated learning outcomes or permanent ad-free status before the submitted build actually supports those claims. Keep the “prototype” label on the current review page. No fabricated reviews, install counts, awards or unavailable app-store buttons.

## Store experiments after a real release
Test one variable at a time: first icon direction, then first screenshot treatment, then headline/copy. Hold traffic source and audience as comparable as possible. Track store-page conversion alongside downstream activation/retention; click-attracting art that disappoints in the first minute is not a win.

No experiments have been launched and no conversion results are available. Do not infer store traction from browser prototype clicks. Policies and required image sizes should be rechecked at submission time.
